# 回测策略记录（stock-sentinel-ai）

> 目的：把已落地/已跑通的回测策略集中记录，便于后续「再回测」直接复用，避免规则散落在代码与日志中。
> 数据/工具位置见 `tools/README.md`；形态定义见 `docs/xingtaidu-patterns.md`。

---

## 〇、通用回测约定（所有策略共用）

- **数据源**：通达信本地日线 `data/hsjday`（二进制直读 → numpy，全市场约 2s），不走 SQLite 存 K 线。
- **复权**：前复权，因子来自新浪 `qfq.js`，存于 `data/kline-full.db`（前复权价 = 不复权价 ÷ f）。
- **防未来函数**：信号在 bar i 收盘后确认，成交固定 bar i+1 开盘；指标只用 ≤ i 的数据。
- **交易成本**：佣金双边万 2.5（最低 5 元）、卖出印花税 0.05%、双边滑点各 0.1%。
- **通用过滤**：上市满 250 日、停牌复牌间隔 >5 交易日跳过、开盘涨停买不进跳过、单日涨跌幅 >21% 视为异常跳过。
- **存储**：回测结果统一落 `data/backtest/`（`patterns/` 形态回测、`strategy1/` 首板回踩策略、`strategy2/` 首板/二板回踩、`strategy3/` CCI+5 周线）。

## 一、策略 #1：首次涨停 + 回踩均线分仓

实现文件：`tools/strategy_limitup_pullback.py`（状态机式，独立于形态引擎）

### 1.1 策略规则（用户定义）

1. **启动信号**：在交易区间内，捕捉某只股票「一波行情的第一次涨停」（非 ST 用 10%、创业板/科创板 20% 阈值）作为启动信号。
2. **分仓买入**：涨停之后，价格第一次回踩到 **5 / 10 / 20 日线** 各形成一个起买点，分 3 次买入（回踩越深买点越低，等于在回调中分批建仓）。
3. **趋势过滤（前置条件）**：回踩买入要求当日 `ma10 ≥ ma20`（处于多头排列的回调中，而非下跌中继）；可用 `--no-trend-filter` 关闭。
4. **止损（按仓位）**：每只仓位「连续 2 个交易日收盘价 ≤ 起买价（未站上）」即止损，第 2 个未站上日收盘离场。
5. **止盈**：内置多种方案做横向对比，最终推荐「沿 5 日线持有」（`ma5_trail`）。

### 1.2 默认参数（`DEFAULT_CFG`）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `start` / `end` | 2000-01-01 / 2099-12-31 | 回测区间 |
| `adj` | qfq | 前复权 |
| `min_list_days` | 250 | 上市满 250 日才参与 |
| `tp_mode` | ma_trail（脚本默认） | 止盈方案，**全市场验证推荐 `ma5_trail`** |
| `peak_thr` | 0.08 | 峰值回撤移动止盈阈值（8%） |
| `target` | 0.20 | 目标价（+20%） |
| `max_hold` | 120 | 单仓最大持有交易日 |
| `trend_filter` | True | 是否要求 ma10≥ma20 |
| `entry_window` | 40 | 涨停后多少交易日内允许回踩买入 |
| `commission` / `min_commission` | 0.00025 / 5.0 | 佣金费率 / 最低佣金 |
| `stamp_tax` / `slippage` | 0.0005 / 0.001 | 印花税 / 滑点 |
| `position` / `workers` | 100000 / 8 | 单仓资金 / 并发数 |

### 1.3 止盈方案一览（`--tp-mode`）

| 模式 | 退出规则 |
|---|---|
| `stop_only` | 仅止损 + 最大持有 120 日（基线，不止盈） |
| `ma5` | 收盘价跌破 5 日线即走（极短线） |
| `ma10` | 收盘价跌破 10 日线即走 |
| `ma20` | 收盘价跌破 20 日线即走（长趋势破位） |
| `peak8` | 自最高点回撤 8% 止盈（移动止盈） |
| `peak12` | 自最高点回撤 12% 止盈 |
| `t20_p8` | 达标 +20% 兑现，或自最高点回撤 8% 止盈 |
| `trend_trail` | 趋势追踪移动止盈：未盈利用原止损保命；盈利后止损线上移至 max(成本价, 峰值×0.92)，回撤 8% 止盈 |
| `ma_trail` | 沿 5/10 日线持有：生命线=10 日线，被有效跌破（收盘破线 + 5日线下叉10日线）才离场 |
| `ma5_trail` | 同上，生命线=5 日线（更紧，推荐） |

### 1.4 止盈方案对比（600 只样本，2014-01-01 起）

| 方案 | 胜率 | 单笔均值 | 盈亏比 | 平均持有 |
|---|---|---|---|---|
| stop_only | 5.8% | **-1.25%** | 0.70 | 17.0 天 |
| ma5 | **45.0%** | +0.08% | 1.06 | 0.6 天 |
| ma10 | 41.1% | -0.10% | 0.94 | 1.2 天 |
| ma20 | 31.3% | -0.12% | 0.95 | 3.8 天 |
| peak8 / peak12 | 22.6% | **+0.27%** | **1.09** | 6.6 天 |
| t20_p8 | 22.5% | -0.17% | 0.94 | 5.4 天 |
| trend_trail | 24.0% | +0.17% | 1.05 | 6.9 天 |
| ma5_trail | 30.95% | +0.179% | 1.061 | 4.15 天 |
| ma_trail | 30.8% | -0.011% | 0.996 | — |

**关键发现**：`peak8 == peak12` 完全一致 → 原「连续 2 日未站上买进价」止损太紧，多数仓位在盈利前就被截掉，移动止盈来不及触发。→ 必须让止损随价格上移，而非死守首日买进价。

### 1.5 推荐止盈策略（最终版：`ma5_trail` 沿 5 日线持有）

> 买入后不主动卖，只要 **收盘价 > 5 日线 且 5 日线 > 10 日线 且 10 日线 > 20 日线**（即「沿 5/10 日线往上走」），就一直持有；一旦生命线被有效跌破（收盘破 5 日线 **且** 5 日线下叉 10 日线）才离场。未走出趋势的早期阶段，仍用「连续 2 日未站上买进价」止损护本金。

**全市场最终结果（ma5_trail，5460 只 / 2000–2026）：**
- 交易 **262,081 笔**，胜率 **32.3%**，单笔均值 **+0.33%**，盈亏比 **1.115**，平均持有 **4.22 天**
- 盈利 +9.90% / 亏损 −4.24%
- 退出拆分：跌破生命线离场 99,373 笔（均值 **+8.10%**，正是「沿 5 日线持有」的果实）；止损离场 162,708 笔（均值 −4.42%，回踩后没走起来）
- 起买点质量：10 日线回踩最好（胜率 34.2% / 均值 +0.54%），5 日线次之（+0.24%），20 日线最弱
- 按年：2024/2025 最好（约 +0.5%），2023/2026 最差（约 −0.4%）

对照上一版 `trend_trail` 全市场：254,973 笔、胜率 25.2%、单笔 +0.49%、盈亏比 1.152、均持 7.27 天。

### 1.6 诚实结论与下一步

- 形态/首板策略**单用只有薄薄的正 edge（单笔 +0.1~0.5%、盈亏比 ≈1.1）**，接近随机，必须叠加过滤：
  1. **大盘择时**：沪深 300 在年线之上才参与，避开 2018/2022/2023 系统性磨损；
  2. **板块强度**：优先选当日/当周涨停家数前 5 板块（原板块轮动框架）；
  3. **量能确认**：回踩缩量、再起放量，过滤假突破；
  4. **仓位**：三个买点不等额，10 日线甜区可加重。

## 二、策略 #2：首板/二板 + 缩量回踩 5/10/20 日线

实现文件：`tools/strategy_first_board_pullback.py`（独立热循环，全市场 5460 只 / 12 线程约 4 分钟）
分析器：`tools/s2_analyze.py`（生成 Markdown 分析报告，含分类/五分位/高低组/过滤模拟/槽位组合模拟）
分析报告：`docs/策略2回踩均线回测分析报告.md`（基线）、`docs/策略2过滤版回测分析报告.md`（过滤版）
结果库：`data/backtest/strategy2/s2b_peak12_full.db`、`s2b_peak8_full.db`、`s2b_vp_full.db`、`s2f_peak12_full.db`

### 2.1 策略规则（用户定义，硬条件）

1. **只做首板 / 二板**：一波连续涨停中的第 1 个或第 2 个涨停板；第 3 个板起不再作为候选（`max_boards=2`）。
2. **排除「前期已经被炒过」的票**：首板日之前 **60 个交易日**内出现过 **连续 ≥3 个涨停板**的形态直接剔除
   （`exclude_lookback=60` / `exclude_height=3`）。全市场校验：首板形态 154,592 个、二板 20,477 个、
   ≥3 连板 11,892 个，其中 **12.4%（21,788 个）**被该条排除。
3. **回踩缩量买入**：最后一板之后的 **40 个交易日**内，价格回踩 **5 / 10 / 20 日线**且当日缩量 →
   **次日开盘买入**（T+1）。

### 2.2 主模型补充的条件（第一版只记录为特征，不强制过滤）

「前期资金没操作过」侧：

| 特征 | 含义 |
|---|---|
| `pre60_n_limitup` | 前 60 交易日涨停次数（0 = 完全没动过） |
| `pre250_n_limitup` | 前 250 交易日涨停次数 |
| `pre60_volmax_ratio` | 前 60 日最大量 / 前 250 日日量中位数（前期是否放过异动大量） |
| `pre60_ret` / `pre60_amp` | 前 60 交易日累计涨幅 / 振幅 |
| `pos_hh250` | 首板前一日收盘 / 250 日最高（位置高低） |
| `dist_ma20_preboard` / `ma_align_preboard` | 首板前偏离 20 日线 / 是否多头排列 |
| `st_like` | 经验推断的 ST（库中 `name` 全空，用「收盘==最高且涨幅≈5%」频次推断） |

「突然 1~2 个涨停吸引人气」侧：

| 特征 | 含义 |
|---|---|
| `lu_vol_ratio` | 板日量 / 板前 5 日均量（放量倍数） |
| `board_amount` | 板日成交额（流动性） |
| `lu_open_pct` / `lu_close_pos` / `lu_is_yizi` | 板日开盘涨幅 / 收盘位置 / 是否一字板 |
| `board_pct` | 板日涨幅（按上市板与日期生效的涨跌幅比例判定：主板 10%、创业板 2020-08-24 前 10% 后 20%、科创板 20%、ST 经验 5%） |

入场/持仓/市场环境侧：`pb_days`（回踩距板日）、`pb_depth`（回踩深度）、`ma_leg`（回踩到哪条线）、
`shrink_vma5` / `shrink_lu` / `vol_ratio_prev`（三档缩量）、`entry_ma_ratio`、
`ma_align_entry` / `trend_ok`、`ret_from_preboard_at_entry`、
`idx_sh_above20/60/250`、`idx_hs300_above60`、`mkt_limitup_cnt`（当日全市场涨停家数）。

共 41 列特征逐笔落库，便于任何切片复查。

### 2.3 入场与出场判定细节（防未来函数）

- **缩量三重条件**：当日量 ≤ 0.8 × 5 日均量 **且** ≤ 1.0 × 板日量 **且** 当日量 < 前一日量。
- **触线条件**：最低价触及均线，且收盘不低于该均线 × 0.98（避免假跌破）。
- **三条腿只取一条**：5/10/20 日线同时满足时，取「离当日最低价最近」的那条记入 `ma_leg`（单票单仓，不做三条腿重复计数）。
- **形态失效**：板后回踩窗口内若再次涨停，本形态作废。
- **买不进保护**：次日开盘即涨停不买。
- **出场**：默认 `peak12`（自持仓期最高收盘回撤 12% 离场）/ 最大持有 60 交易日 / 持有超 400 自然日强平 / 一字跌停当日顺延下一日卖。
- **成本**：佣金双边万 2.5（最低 5 元）、卖出印花税 0.05%、双边滑点各 0.1%。

### 2.4 默认参数（`DEFAULT_CFG`）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `max_boards` | 2 | 只做首板/二板 |
| `exclude_lookback` / `exclude_height` | 60 / 3 | 前 60 交易日出现过 ≥3 连板则剔除 |
| `entry_window` | 40 | 板后多少交易日内允许回踩买入 |
| `entry_mode` / `max_break_below_ma` | touch / 0.02 | 最低价触线且收盘不低于均线 2% |
| `shrink_vma5` / `shrink_lu` / `require_vol_down` | 0.80 / 1.00 / True | 缩量三重条件 |
| `exit_mode` | ma5_trail20（脚本默认）/ **peak12（实盘推荐）** | 退出方案 |
| `max_hold` / `max_cal_days` | 60 / 400 | 最大持有交易日 / 自然日 |
| `min_list_days` | 250 | 上市满 250 日才参与 |
| `commission` / `stamp_tax` / `slippage` | 0.00025 / 0.0005 / 0.001 | 成本 |

### 2.5 退出方案横比（全市场 5460 只 / 2000-2026 / 三套同候选池 31,929 笔）

| 退出模式 | 笔数 | 胜率 | 单笔均值 | 中位数 | 盈亏比 | 平均持有 |
|---|---:|---:|---:|---:|---:|---:|
| **`peak12`（推荐）** | 31,929 | **35.41%** | **+0.898%** | -5.464% | **1.148** | 26.58 |
| `peak8` | 31,929 | 33.98% | +0.302% | -4.506% | 1.065 | 15.45 |
| `vp_trail`（放量破 5 日线 = 量价） | 31,929 | 24.56% | +0.063% | -2.704% | 1.018 | 9.74 |

800 只样本（2014 起）补充横比：`peak12_sl10` +0.736%、`peak12_sl8` +0.637%、`ma5_trail20` −0.123%、`stop_only` +0.000%。

**结论**：候选池完全相同，只有退出规则不同 —— **`peak12`（自高点回撤 12% 跟踪止盈）最优**；
加硬止损（−8% / −10%）不提升单笔均值；「看着量价离场」在本次数据上**最差**，与常见主观经验相反。

### 2.6 全市场结果（baseline + peak12）

- 交易 **31,929 笔**，胜率 **35.41%**，单笔均值 **+0.898%**，中位数 **−5.464%**，盈亏比 **1.148**，平均持有 **26.6** 交易日
- 平均盈利 +19.73% / 平均亏损 −9.42%；单笔最好 +535.91% / 最差 −92.14%
- 分板高：首板 29,001 笔（+0.890%）· 二板 2,928 笔（+0.986%）
- 分回踩腿：5 日线 20,127 笔（+0.806%）· 10 日线 8,097 笔（+0.971%）· 20 日线 3,705 笔（**+1.243%**）
- 分退出原因：峰值回撤 12% 离场 28,025 笔（**均值 −1.303%**）· 持满 60 日「到期」3,644 笔（**均值 +17.635%**）· 数据结束强平 255 笔 · 超自然日上限 5 笔
- 收益高度依赖右尾：最赚 5%（1,596 笔）占全部正收益的 **49%**；剔除最赚 5% 后剩余 30,333 笔均值 **−2.677%**
- 分年最好：2007 +17.885% / 2006 +16.252% / 2015 +13.519% / 2014 +7.970% / 2000 +7.448% / 2025 +4.026%；
  最差：2011 −6.393% / 2004 −6.185% / 2002 −6.104% / 2008 −6.054% / 2018 −5.911% / 2017 −5.114%
- **组合模拟（K 槽位逐日盯市，1/K 资金、满仓弃信号、随盈亏复利）**：
  K=10 期末净值 **0.81**（年化 −0.8%，最大回撤 −86.9%）→ 单笔正期望**没有**转化成可交易的组合收益

### 2.7 过滤版结果（filtered + peak12）

过滤档案 `FILTERED_PROFILE`（三条均为事前可知，不含未来函数）：

1. `f_pre_no_limitup`：前 60 交易日**完全无涨停**（用户核心条件「前期资金没动过」）
2. `f_index_above='250'`：**上证在年线之上**才买（择时，单项最强）
3. `shrink_vma5=0.60`：缩量更严格（<0.6 倍 5 日均量）

结果：**9,684 笔**，胜率 **38.21%**，单笔均值 **+2.175%**，中位数 −4.495%，盈亏比 **1.384**，平均持有 31.8 交易日。

| 槽位数 K | 采用/丢弃(满仓) | 期末净值 | 年化 | 最大回撤 | 夏普 |
|---:|---|---:|---:|---:|---:|
| 5 | 463 / 9,221 | 3.00 | +4.2% | −59.0% | 0.38 |
| 10 | 944 / 8,739 | 6.63 | **+7.4%** | −44.0% | 0.60 |
| 20 | 1,822 / 7,859 | 9.36 | **+8.7%** | −36.5% | 0.73 |
| 50 | 3,970 / 5,707 | 5.42 | +6.5% | −37.2% | 0.64 |

即：**同样的候选池，加上「前期没被炒过 + 大盘在年线上 + 更严格的缩量」三条过滤，单笔均值从 +0.898% 提升到 +2.175%，
组合从净值 0.81 变为 6.63**。但最大回撤仍在 −36%~−44%，不能直接当实盘方案。

### 2.8 收益高 / 低到底差在哪（用户问题）

按单笔收益首尾各 25% 分组（baseline）：

- 高收益组 7,982 笔：均值 **+26.86%**，中位 +17.83%
- 低收益组 7,982 笔：均值 **−13.80%**，中位 −13.11%

| 维度 | 高收益组 | 低收益组 | 差值 / 标准差倍数 | 结论 |
|---|---:|---:|---:|---|
| 持有交易日 | 38.5 | 14.9 | +1.28 sd | **结果变量**：赚大钱的都是活满 60 日的趋势股 |
| 板前位置/250 日高 | 0.712 | 0.695 | +0.11 sd | 差别很弱，但**越高越好**（突破型 > 低位型） |
| 前 60 日涨停次数 | 0.878 | 1.021 | −0.10 sd | 越少越好，支持「前期资金没动过」 |
| 板日成交额 | 3.81 亿 | 4.62 亿 | −0.10 sd | 越小越好（小票弹性大） |
| 板日放量倍数 | 3.29 | 3.37 | −0.03 sd | 几乎无区分度 |
| 缩量比 / 回踩深度 / 板高 | ≈ 持平 | ≈ 持平 | <0.05 sd | 无区分度 |

五分位单调性（数值特征，baseline，区分度排序）：

| 特征 | 最好组 | 最差组 | 方向 |
|---|---:|---:|---|
| 板日成交额 | +3.56%（2.6 百万~8.2 千万） | −1.04%（5.6 亿以上） | **单调：成交额越小越好** |
| 板前位置 / 250 日高 | +3.52%（≥0.83） | −0.76%（0.58~0.68） | **单调：位置越高越好** |
| 前 60 日最大量/中位量 | +1.90%（2.7~3.7 倍） | −0.15%（>7.5 倍） | 倒 U：前期温和放量最好，极端巨量最差 |
| 前 60 日涨停次数 | +1.30%（0~1 次） | +0.09%（2~13 次） | **单调：越少越好** |
| 缩量比（量/板日量） | +1.56%（<0.37） | +0.13%（0.76~1.0） | **单调：越缩越好** |
| 回踩距板日 | +1.93%（1~3 日） | +0.10%（5~6 日） | 早回踩好，但样本少 |
| 板日放量倍数 | +1.32%（2.2~3.1 倍） | +0.49%（>4.7 倍） | 倒 U：3 倍上下最好 |

分类维度：二板 +0.986% > 首板 +0.890%；20 日线腿 +1.243% > 10 日线 +0.971% > 5 日线 +0.806%；
ST 经验推断 +4.297%（1,158 笔，样本少）；一字板 +1.172%（787 笔）；
**上证在年线上 +1.889% / 年线下 −0.518%**，沪深300 在 60 日线上 +1.888% / 线下 −0.082%。

**一句话结论**：单笔收益的高低**几乎不由入场时的形态参数决定**（除成交额、位置、前期涨停次数三个弱单调因子外，
其余特征区分度都 <0.15 个标准差），而是由 **①是否踩在大盘上行周期（年线上）、②买入后能不能走出 60 日趋势（到期组 +17.6% vs 回撤组 −1.3%）** 决定。
即这是个**低胜率、强右尾、强 beta** 的策略：必须靠择时 + 严格的事前过滤来提高胜率，靠 12% 跟踪止盈去兑现右尾。

### 2.9 已知问题与下一步改进方向

1. **信号量远超资金容量**：26 年 31,929 个信号（过滤版 9,684 个），而 K=10 槽位只能接下 944 个。
   → 需要**同日候选打分排序**（目前只是先到先得），这是把单笔期望转成组合收益的关键一步。
2. **中位数仍为负**（−4.5%）：收益全靠右尾（最赚 5% 贡献 49% 正收益），必须靠严格过滤提高胜率，不能靠"感觉"加仓。
3. **回撤仍大**：过滤版组合最大回撤 −36%~−44%，需要仓位管理（大盘择时 + 单票仓位上限 + 并发上限）。
4. **量价退出被证伪**：`vp_trail`（放量跌破 5 日线离场）三套里最差（+0.063%），不要用"看量价"主观离场替代 12% 跟踪止盈。
5. **最初的假设需要修正**：「低位、前期没人炒的票突然涨停」里，**「低位」这一半与数据相反**——
   `pos_hh250` 越高收益越好。可能是小市值/突破形态的代理，需要再切片验证（例如按流通市值分组）。
6. **待验证的加分层**：沪深300 在 60 日线上 + 当日涨停家数<80 + 前 60 日振幅<60% 的组合（5,627 笔，+3.254%，盈亏比 1.572）；
   板日放量 <2 倍（1,726 笔，+2.973%，胜率 40.1%，盈亏比 1.546）——均为样本内结果，需分年稳定性检验后才可采纳。
7. **数据层限制**：退市股 301 只（幸存者偏差可控但存在）；复权残余跳空 1,504 处 / 1,784 万根（0.0084%）；
   库中 `name` 全空导致 ST 只能经验推断（全市场命中 72/5460）。

### 2.10 已修复的实现缺陷（回测可信度）

1. **`peak12` 误用 8% 阈值**：原代码所有 `peak*` 模式取同一个 `peak_thr`，导致 `peak12` 与 `peak8` 结果完全一致 → 已按 `MODE_PEAK_THR` 分模式取值。
2. **自然日跨度用 YYYYMMDD 整数相减**：跨月/跨年会被放大（`20070702−20070627 = 75`，跨年 +10000），

   并用 4,000 个随机日期 + 闰年/跨年边界对照 `datetime.date.toordinal()` 校验（差值恒为 0）。
3. 其余已校验项：5460 只股票 raw（不复权）与前复权 bars 长度/日期 **完全一致（0 处错位）**；
   规则 3 的 60 日窗口排除逻辑用 000001/000002/000004 三例人工抽查正确；逐笔核对 600519 2008-03-13 买入 104.14、03-18 收 99.54 出场 −4.62% 与代码一致。

#### （6）诚实结论

1. 「越接近 250 日新高越好」**方向正确但已衰减**：全样本单调，现代市场只剩 ≥0.95 一档为正。
2. 排除 ST / 次新对收益**基本无害也无益**，属于风控动作，不是增益来源。
3. 现代市场**唯一稳健的正向增益是「板日成交额年度分位 ≤30%」**（U 型左端，验证段同向，保留 21% 笔数）。
4. 组合能把现代市场基础池从 −0.513% 拉到 +1.178%，但**中位数仍为负（−3.3%）**，净值年化仅 +1.8%，
   仍是靠右尾的低胜率策略；不能据此认为「已经找到稳定盈利的配方」。
5. 剩余改进方向未变：**同日候选打分排序**（当前先到先得）、仓位/择时管理，以及按流通市值再切片验证
   「低成交额 ≈ 小市值」这一假设（当前数据层无市值字段）。

#### （8）诚实结论

1. **在这套「首板/二板 + 缩量回踩均线」信号族里，真实可执行口径做不到月 20%。**
2. 证据链：12 种入场形态 × 12~14 种退出形态 × 56 个维度、共 13.9 万组组合搜索后，两段一致的组合只有 994 个，
   最高「最差段月均」+1.6%；连**用了未来信息**的事后完美退出（+8.65%/月）和卖在窗口最高点（+10.15%/月）都不够；
   只有「只买事后最强前 1~2%」这种 100% 胜率的未来函数才到 +17~18%，且它月≥20% 的月份也只占 36.7%~46.7%。
3. 继续加维度只会**过拟合**：本轮 39 维 → 56 维，通过一致性的比例反而更低（2.46% vs 随机 20.2%）。
4. 这套信号的真实画像：胜率 39%~42%、**中位数 −3% ~ −5.8%**、正收益完全来自右尾，
   基准 K=3 年化 +3.1%、最大回撤 −52.7%。

**能真正提高收益的四个方向（按性价比排序）**：

1. **换形态族**：打板 / 首板尾盘追涨 / 龙头分歧回封 / 反包，这批信号的右尾比「缩量回踩」厚得多（需用户确认后开发）；
2. **降低资金闲置**：K=3 时大量时间空仓，用「回踩 + 板块共振」提高信号密度，才能让月均接近单笔均值×周转率的理论上限；
3. **接受现实目标**：把目标改成 **年化 15%~25% + 回撤可控**，本轮已有对应组合（如 `cnt_le50+idxsh60+volmax35 × hold60`：两段月均 +1.6%，年化约 +21%，回撤 −17%~−37%）；
4. **杠杆**：在上述基础上加 1.5~2 倍杠杆才能摸到月 3%~4%，同时回撤放大到 −40% 以上、月波动 20%+，**不可能到月 20%**。

### 2.16 「首板打板排不进队」的量化验证（2026-09-14）

用户质疑：**首板打基本不可能排得进去**。→ 质疑成立，而且比直觉更严重：这套 +9.25%/月 的收益，
几乎全部藏在「按定义就买不到」的那一档里。

#### （1）证据 A：旧打板库 38,709 笔里，炸板样本 = 0

工具 `tools/s2_old_db_audit.py`，原始日志 `data/backtest/strategy2/_olddb_audit.log`：

```
旧打板库 38,709 笔；lu_is_yizi 分布：[(0, 36907), (1, 1802)]
新扫描 2016+ 触板事件 310,310
旧库在新全量扫描中的匹配：封板 4,601 / 炸板 0 / 未命中 34,108
2016+/pos>=0.83：新扫描 封板 29,299（旧库收录 4,601）、炸板 281,011（旧库收录 0）
```

`s2a_b1c.db` 的买入价 = 板日收盘价，而板日收盘价等于涨停价只发生在**当日收盘封板**的样本上。
所以该库天然只收录封板样本：2016 年以来 281,011 个「盘中触板但收盘炸板」的样本，它**一个都没收**。

**结论**：`+9.25%/月` 的口径是「只要摸到涨停就一定按涨停价买到，并且只买当天封板的票」。
前者是 100% 成交假设，后者含未来函数 —— **这是上界，不是可实现收益**。

把 66,405 个触板事件按「能不能买到」分组；买入价 = 当日收盘价（尾盘挂单：封板票排队、

#### （5）同日抢槽位的敏感性（`_slot_diag.log`）

K=3、k=0、买入价 = 涨停价时，同一天信号的选取顺序会翻转结论：

| 同日选取顺序 | K3 月均 | 实成单笔 | 其中 一字/封板/炸板 |
|---|---:|---:|---|
| 原始（按代码） | -3.05% | -0.298% | 558 / 2,940 / 2,016 |
| 随机（按日种子） | -3.57% | -0.348% | 568 / 3,020 / 2,040 |

#### （6）诚实结论

1. **用户判断成立**：这套「首板/二板 → 隔夜跳空」的 edge 在现实成交约束下基本吃不到。
   名义 K3 +9.25%/月 的完整链条是「摸到涨停 → 一定能买到 → 而且只买当天封板的票」，
   后两环都不成立。
2. **月 ≥10% 在可成交口径下不可达**（与 2.14.5 的 bootstrap 一致：名义月均 +7.26%、
   重采样后 ≥10% 概率 0.0%）。可成交口径的现实量级是 **-4%/月 上下**（-3.93% ~ -4.50%）。
3. 若要继续，**唯一还没被证伪的口径**是「尾盘按收盘价买封板票」。它本质上仍是排队：
   封板票的收盘价就是涨停价，能否成交取决于尾盘集合竞价的卖盘量，**成交率不是 100%**。
   该口径无过滤全池为 +9.70%/月（随机顺序，回撤 -30.8%），但必须连带标注这个排队假设。

## 三、策略 #3：CCI(89) ≥ 0 + K 线站上 5 周线（2026-09-15）

实现文件：`tools/strategy_cci89_ma5w.py`（状态机回测）｜分析器：`tools/s3_analyze.py`｜独立复核：`tools/verify_s3_trades.py`
完整报告：`docs/策略3CCI89站上5周线回测报告.md`；明细：`data/backtest/strategy3/s3_*.{csv,json,html}`

### 3.1 策略规则（用户定义）

**买入（信号日收盘确认，次日开盘成交）**

1. `CCI(89) ≥ 0`（通达信口径：`TP=(H+L+C)/3`，`CCI=(TP−MA(TP,89))/(0.015×AVEDEV(TP,89))`，用平均绝对偏差而非标准差）；
2. 收盘价「站上」5 周均线（`close > MA5W`）。

**卖出**：收盘价「跌破」5 周均线（`close < MA5W`）即离场，默认次日开盘成交（`--exit-fill close` 可改为跌破当日收盘卖）。

**周线口径（`--week-ma-mode`）**：`live`（默认）＝ 5 周线取「最近 5 个自然周的当周最新收盘」均值，含本周未走完的周 K；
`closed` ＝ 只用已收完的 4 根周 K + 当周，信号更保守。

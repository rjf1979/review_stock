# Sequoia-X 六策略同口径回测报告（智诊盯盘，2021-01-04 ~ 2026-09-18）

> 研究性离线回测，不构成投资建议，也不构成任何收益承诺。
> 本文所有数字均由本仓库脚本在本机行情上重算得到，可按下文命令逐条复现。
> 全文只回答一个问题：**Sequoia-X 的策略条件，在本项目的数据、成本与退出口径下，
> 有没有一条值得提升为智诊盯盘的正式选股规则？**

## 一、来源、边界与这次做了什么

**来源**：开源项目 `sngyai/Sequoia-X`（A 股自动选股系统，多形态扫描 + 收盘后推送飞书；
本次核实时 GitHub 显示 7421 star，最后推送 2026-07-10）。其 `sequoia_x/strategy/` 下共 7 个
策略文件：`ma_volume`、`turtle_trade`、`high_tight_flag`、`limit_up_shakeout`、
`uptrend_limit_down`、`rps_breakout`、`private_placement`。

**许可与复制边界**：该仓库**根目录没有 LICENSE 文件**，只有 `README.md` 末尾声明 “MIT”。
在许可证正文缺失的情况下，本次**不复制其任何源码**，只按其公开的策略条件描述，在本项目的
指标字典上重写为等价的向量化布尔序列（`tools/patterns/sequoia_x.py`），并保留“信号在当根
K 线收盘确认”的语义。

**数据层边界**：Sequoia-X 用 baostock 复权日线存 SQLite；本项目用本地通达信日线
（`data/hsjday`）+ `data/kline-full.db` 的 qfq 因子。两者股票池、复权、除权处理都不同，
所以**命中不会逐只一致**，可比的只有「条件本身」和「同一套退出规则下的统计量」。

**只取 6 条**：`private_placement`（定增）依赖公告/基本面数据，本项目回测链路只有日线，
无法等价重写，故本轮不纳入。

**本次交付的代码（全部 `enabled:false`，不影响生产选股）**：

| 文件 | 作用 |
| --- | --- |
| `tools/patterns/sequoia_x.py` | 6 个形态的定义（pid 前缀 `sqxm_`） |
| `tools/pattern_exits.py` | 为 6 个形态各加一条显式退出规则（与现有 25 条参数组合均不重复） |
| `tools/rps_threshold.py` | 离线计算并缓存 `sqxm_rps_breakout` 需要的横截面 90 分位阈值 |
| `tools/indicators.py` | `compute_indicators()` 增补 `amount`（元）与 `turnover`，不改旧调用语义 |
| `tools/patterns/__init__.py` | `register()` 支持 `cross_section` 元数据；注册顺序 = 25 旧 + 6 新 |
| `tools/xingtaidu_backtest.py` | 支持横截面阈值注入（`_align_rps`），并把这 6 条并入趋势/突破/反转分组（只影响 `--exit-mode uniform`） |

**明确未动**：前端、`rules-store.js` 的 `DEFAULT_RULES`、已启用的 `rsi_low_turn` v4 / `limit_pullback` v4、
`tools/xingtaidu_screen.py`。6 条新形态不进任何候选池。

## 二、六条策略的原口径（逐条对照）

| 形态 | 名称 | 入场条件（信号日收盘确认） |
| --- | --- | --- |
| `sqxm_ma_volume` | 均线放量金叉 | MA5 上穿 MA20（昨日 `ma5<ma20`、今日 `ma5>ma20`）且当日量 > 20 日均量×1.5 |
| `sqxm_turtle_trade` | 海龟 20 日新高 | 收盘 > 前 20 日最高，且成交额 > 1 亿，且收盘>开盘、收盘>昨收 |
| `sqxm_high_tight_flag` | 高旗形缩量整理 | 40 日 high/low > 1.6，10 日 high/low < 1.15，10 日最低 ≥ 40 日最高×0.8，当日量 < 前 20 日均量×0.6 |
| `sqxm_limit_up_shakeout` | 涨停洗盘不破昨收 | 昨日 close ≥ 前日 close×1.095，今日收阴，今日量 > 昨日量×2，今日最低 ≥ 昨日收盘 |
| `sqxm_uptrend_limit_down` | 上升趋势放量跌停 | 昨日 MA20 > MA60，今日 close ≤ 昨收×0.905，今日量 > 20 日均量×2 |
| `sqxm_rps_breakout` | RPS 极强动量突破 | 近 120 日涨幅处于全市场前 10%（横截面分位 ≥ 90），且 close ≥ 120 日最高×0.90 |

> 口径说明：`sqxm_ma_volume` / `sqxm_high_tight_flag` / `sqxm_rps_breakout` 用“不含当日”的
> 前序窗口；`sqxm_rps_breakout` 的横截面阈值由 `tools/rps_threshold.py` 在**每个交易日**上
> 用全市场参与排名算出（股票池 = 上市满 250 根的 `Market`），引擎按日期对齐注入，未注入时该
> 形态返回全 False（不会误命中）。

## 三、回测口径（三次运行完全一致）

- 区间：**2021-01-04 ~ 2026-09-18**（本地日线最新到 2026-09-11，`--end` 不会引入未来数据）
- 股票池：全市场 **5460 只**（含已退市股），6 分片并行
- 引擎：`tools/xingtaidu_backtest.py`，含交易成本，结构止损 / 分批止盈 / 跟踪退出 / 时间止损口径统一
- 对照锚点：`rsi_low_turn` v4（`low=20`）与 `limit_pullback` v4，用 `tools/backtest_v4_both.json`
  **同一次运行、同一退出口径**产出，已与历史 JSON 逐位一致（证明本轮改动没有污染旧链路）

退出口径有两种，用来区分“是入场条件不行，还是退出规则不行”：

- **spec 退出**：本报告为 6 条新形态各自定义的显式退出规则（`--exit-mode pattern`）
- **v4 退出**：`first_r_multiple=6.0` / `first_exit_fraction=0.0` / `no_target=true`，
  即“首目标 6R、不减仓、关闭测量目标，只做结构止损 + 跟踪”，与 v4 两条上线规则完全相同

## 七、结论与建议

1. **六条策略全部维持 `enabled:false`**，不进入 `rules-store.js` 的 `DEFAULT_RULES`，
   不进入任何候选池或扫描链路。本轮只做口径落地与证据留档。
2. **本项目不建议直接采用 Sequoia-X 的原始选股条件**。原因不是“形态写错了”，
   而是它们的入场缺少本项目 v4 反复验证过的核心过滤——**前期深跌（60 日跌幅 ≤ −30%）
   与相对强度（20 日相对沪深 300 ≤ −5pp）**。这两个过滤器正是 v4 把 PF 从 1.28 抬到
   5.88 的关键，而 Sequoia-X 的形态大多在“追强势 / 追突破 / 追反弹”，方向相反。
3. **`sqxm_turtle_trade` 与项目定稿方向直接冲突**。海龟 20 日新高是纯追高型，
   其 150,667 笔样本（占六策略全部信号的 57%）在两个退出口径下 PF 都 < 1。
   项目已定稿「防追高」原则，该形态**不应**在任何情况下提升为正式规则。
4. **如果仍想继续用这 6 条形态，正确做法是给它们加过滤，而不是调退出规则**：
   即“原形态条件 + v4 同等的 60 日跌幅 / 相对强度过滤”，重新回测后看样本量与 PF 是否
   落到 v4 的可比区间。这属于独立的 NEW 任务，不在本次 P1 范围内。
5. `sqxm_rps_breakout` 的横截面实现（`tools/rps_threshold.py` + 引擎注入）是**可复用资产**：
   它让回测引擎第一次具备“按交易日做全市场分位”的能力，后续任何横截面形态都能直接接。

## 九、已知限制

- **数据层不同**：本项目用本地通达信日线 + qfq 因子，Sequoia-X 用 baostock 复权日线，
  命中股票不可能逐只一致；本文所有结论只对本项目的数据与成本口径成立。
- **本地日线最新到 2026-09-11**，2026-09-14 ~ 09-18 无 bar，区间尾部略短于名义结束日。
- **横截面阈值按本项目股票池重建**，与 Sequoia-X 的 RPS 定义（欧奈尔 RPS，通常按更长周期
  与更宽股票池排名）只是近似。
- 回测含成本但不含滑点后的冲击成本与涨跌停不可成交情形，真实可执行性弱于表内数字。
- Sequoia-X 仓库根目录无 LICENSE 正文，本文未复制其源码；如需直接复用其代码，
  应先在原仓库确认授权范围。

## 十、进阶实验：给六策略加上 v4 同等过滤（2026-09-20 追加）

第七节建议的下一步是「原形态 + v4 同等过滤」，本节就是这次实验的结果。
结论先说：**过滤不能救这六条策略，只会把样本打没**——因此不建议继续走这条路。

### 10.1 做法

六个形态接上项目共享的 `_ctx_filter`（参数缺省时信号与原口径完全一致，P1 基线可复现），
过滤参数只经 `--config` 注入，不改形态默认定义：

| 配置 | 过滤条件 | 退出 |
| --- | --- | --- |
| `tools/backtest_sequoia_x_v4gate.json` | 60 日跌幅 ≤ −30% **且** 20 日相对沪深 300 ≤ −5pp | 各形态 spec |
| `tools/backtest_sequoia_x_v4gate_ride.json` | 同上 | v4（6R/不减仓/no_target） |
| `tools/backtest_sequoia_x_dropgate_ride.json` | 只加 60 日跌幅 ≤ −30% | v4 |
| `tools/backtest_sequoia_x_rsgate_ride.json` | 只加 20 日相对强度 ≤ −5pp | v4 |

复现（四组各跑一次，`-Patterns` 与第八节相同；结果文件 `xingtaidu_sequoia_x_gate_spec_*`、
`xingtaidu_sequoia_x_gate_v4exit_*`、`xingtaidu_sequoia_x_dropgate_v4exit_*`、
`xingtaidu_sequoia_x_rsgate_v4exit_*`）：

```powershell
powershell -File tools/run_backtest_parts.ps1 -ExitMode pattern -Patterns <六条> `
  -Config tools/backtest_sequoia_x_v4gate.json -OutDir parts_sqxm_gate_spec
powershell -File tools/run_backtest_parts.ps1 -Patterns <六条> `
  -Config tools/backtest_sequoia_x_v4gate_ride.json -OutDir parts_sqxm_gate_ride

  -Config tools/backtest_sequoia_x_rsgate_ride.json -OutDir parts_sqxm_rsgate_ride
```

### 10.2 结果：样本量塌陷，且赢面集中在 2024

| 配置 | 笔数 | 胜率 | PF | 平均净收益 |
| --- | ---: | ---: | ---: | ---: |
| 无过滤 · spec 退出（第五节） | 265,242 | 48.39% | 0.8030 | −0.78% |
| 无过滤 · v4 退出（第六节） | 265,242 | 28.22% | 0.8949 | −0.57% |
| **v4 同等过滤 · spec 退出** | **409** | 70.42% | 2.0951 | +2.72% |
| **v4 同等过滤 · v4 退出** | **409** | 29.83% | 1.2848 | +1.67% |
| 只加跌幅过滤 · v4 退出 | 1,583 | 27.80% | 1.0032 | +0.02% |
| 只加相对强度过滤 · v4 退出 | 10,818 | 29.40% | 1.0317 | +0.17% |

三条关键事实：

1. **信号量从 265,242 掉到 409**（5,460 只 × 5.7 年全市场，平均每只股票不到 0.08 笔）。
   `sqxm_rps_breakout` 在过滤后**一笔都不剩**——「120 日涨幅全市场前 10%」与「60 日跌幅
   ≤ −30%」在定义上互斥；`sqxm_turtle_trade` 只剩 2 笔。二者都是追强势型，与「前期深跌」
   过滤天然冲突，这正是第七节第 2 条的量化证据。
2. **过滤后的收益几乎全部来自 2024 年**（`sqxm_ma_volume` 338 笔里 207 笔在 2024，
   `sqxm_limit_up_shakeout` 23 笔里 17 笔在 2024）。剔除 2024 年后：

| 形态（v4 同等过滤） | spec 退出 ex-2024（n/胜率/PF） | v4 退出 ex-2024（n/胜率/PF） |

   剔除 2024 后只剩 6 笔，属统计噪声，不构成任何证据。
3. **对照 v4 基线**（8,560 笔 / 胜率 60.74% / PF 4.4023）：过滤后的六策略合计 409 笔、
   PF 1.2848（v4 退出），既没有样本量也没有盈亏水平，**不具备提升为正式规则的条件**。

### 10.3 本节的结论

- 六条 Sequoia-X 策略维持 `enabled:false`，**不再继续「原形态 + v4 过滤」这条路线**。
- 真正被这次实验证实的是 P1 的判断：这六条策略与本项目 v4 的核心过滤（前期深跌 +
  相对走弱）方向相反，二者叠加只会互相抵消。
- 可复用的正向资产仍保留：横截面阈值能力（`tools/rps_threshold.py` + 引擎注入）
  与共享过滤接口（`_ctx_filter`），后续新形态可直接使用。

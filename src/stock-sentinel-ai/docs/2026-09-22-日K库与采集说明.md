# 智诊盯盘 · 日K线库与采集说明

> 范围：`E:\tdx_data`（日K线，每只股票**上市至今**）。本文是**已实现**的记录。
> 日期：2026-09-22。实现：`tools/collect_tdx_daykline.py`（采集/校验）、

## 1. 为什么要单独采

日K不是拿不到，而是**渠道不同**：

| 来源 | 范围 | 问题 |
| --- | --- | --- |
| 通达信客户端 `D:\new_tdx\vipdoc\*.day` | 2000-01-04 ~ 今 | **2012–2020 整段没有**、2021 只有 103 天（缺 1–7 月） |
| 厂商按日打包 `g4day/g3day/newday` | 2013-01-04 ~ 今 | 四代格式，**转档只有 GUI 会做**；本机 WSL 未安装 |
| 项目自有 `data/hsjday` | 1990-12-19 ~ 2026-09-18 | 完整（回测在用） |
| **行情服务器 K 线接口** | **每股上市至今** | ✅ 本方案 |

关键实测：**pytdx 自带 104 台服务器里只有国泰君安那 6 台能出 K 线**
（`117.34.114.15/16/17/18/20/27:7709`）；厂商镜像以及其余 25 台可达服务器
`get_security_bars` 一律返回空——这也是先前「服务器 K 线接口全废」这个错误结论的来源。

## 2. 落盘格式与契约

**就是通达信原生 `.day`（32 字节定长）**，因此现有挖掘链零改动即可读：

```
E:\tdx_data\sh\lday\sh600519.day
E:\tdx_data\sz\lday\sz300750.day
```

```python
from kdata import Market
mkt = Market(r'E:\tdx_data')          # 默认是 data/hsjday，这里换根目录
bars = mkt.load('600519', adj='qfq')  # 复权仍走项目既有的因子链
```

| 字段 | 编码 |
| --- | --- |
| 日期 | `uint32` YYYYMMDD |
| 开/高/低/收 | `uint32` = 价格 × 100（分） |
| 成交额 | `float32`，元（服务器原值，**与 hsjday 完全一致**） |
| 成交量 | `uint32`，**股** = 源「手」× 100 |
| 保留 | 0 |

价格**未复权**（与 `hsjday` 同口径，逐根一致）。

## 3. 覆盖与精度（实测）

| 项 | 实测 |
| --- | --- |
| 范围 | **每股上市至今**（600000 = 1999-11-10 起；600519 = 2001-08-27 起） |
| 与 `data/hsjday` 逐根比对 | **OHLC 完全一致（最大差 0.0000 元）**，成交额一致 |
| 成交量 | 源以「手」截断 + float32 传输：绝对 ≤1 手，**中位相对误差 0.000218%**，最大 0.00001% |
| 指数 | 必须用 `get_index_bars`；`get_security_bars` 对指数返回乱码日期 |
| 板块 | 沪主板/深主板/创业板/科创板/北交所均可 |

### 已知口径限制：成交量 uint32 上限

`.day` 的成交量是 `uint32`（股），**装不下超过 42.9 亿股的天量日**。实测包钢股份
`2025-10-14` 成交 51.7 亿股即超出。处理方式：**钳到 u32 上限**，并把真值写进
`report/volume-clamped.json`，**不静默回绕、不静默改写**。这类根全市场只有个位数，
对形态挖掘无影响（量相关形态都用相对量）。

## 4. 用法

```powershell
# 全量（约 5221 只，含科创板；单次约 40 分钟）
python tools/collect_tdx_daykline.py --workers 6

# 试跑
python tools/collect_tdx_daykline.py --root E:\tdx_data\_test --limit-codes 5

# 日常增量：每只只取最新 800 根并与现有文件合并
python tools/collect_tdx_daykline.py --incremental

# 只校验（结构 + 与 data/hsjday 逐根比对）
python tools/collect_tdx_daykline.py --verify

# 只要上证主板+深证主板+创业板（不含科创板）
python tools/collect_tdx_daykline.py --boards sh-main,sz-main,chinext
```

股票池口径与 `tools/kdata.py` 的 `is_stock()` 对齐（`sh 60/68` + `sz 000/001/002/003/004/300/301`），
所以新库是 `hsjday` 的 drop-in 替代。断点续爬按**代码**记录（`state/daykline-codes.json`），
增减板块不会互相干扰。落盘原子替换（`.tmp` → rename），不产生半截文件。

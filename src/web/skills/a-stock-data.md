# 行情日报 A 股数据

本项目的数据采集规范由 `../a-share-daily-review/references/data-sources.md` 定义。执行采集或修复前必须读取该文件。

## 核心约束

- 腾讯优先用于主要指数，按 GBK 解码。
- 东方财富只用于其独有字段与全市场分页，所有请求串行限流。
- 同花顺热点空涨幅必须归一化为 `null`，不能变成 0。
- 历史日期必须验证响应日期，不能用当前快照冒充。
- 全市场分页累计不足 1,000 条时拒绝计算广度；目标应覆盖约 5,000 只以上有效 A 股。
- 池数据按证券代码去重，但同一股票的板高与行业证据必须保留。
- 原始响应、请求日期、抓取时间和错误原因应随交易日快照持久化。

需要生成日报时，同时使用项目 Skill `a-share-daily-review`。

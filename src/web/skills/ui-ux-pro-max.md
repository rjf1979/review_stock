# 行情日报 UI 工程基线

现有项目设计系统优先。日报报告必须读取 `../a-share-daily-review/references/report-layout.md`，并以 2026-08-18 报告为视觉回归基准。

## 必须满足

- 使用语义颜色、间距、圆角、文字、边线和状态 token，避免散落的一次性值。
- 正文对比度至少 4.5:1；焦点清晰；按钮触控尺寸至少 44px。
- 所有异步操作提供 loading、success、empty、error 状态，状态变化使用 `aria-live`。
- 报告和后台在 375、768、1024、1440px 无水平溢出。
- 支持键盘操作、200% 文本缩放和 `prefers-reduced-motion`。
- 打印报告保持高对比、隐藏交互控件、减少不合理分页断裂。
- 金融后台保持安静、紧凑、可扫描；不用营销式大标题、装饰性卡片或无意义动画。

完成前检查桌面、移动、加载、空数据、错误、键盘焦点和打印状态。

# 源码目录

`src/` 按产品形态划分，避免桌面端、Web 平台和未来移动端混放：

```text
src/
├─ desktop/  Windows Electron 桌面软件
├─ web/      Web 官网、报告平台与后台
└─ app/      未来移动端工程占位
```

## 目录边界

- `desktop/` 可以独立安装和运行，不依赖 Web 平台；本地使用公开行情接口和 SQLite。
- `web/` 负责官网、报告展示、后台和外部报告上传，生产环境使用 PostgreSQL。
- `app/` 目前不包含实现。开始移动端开发时应在该目录建立独立包管理和构建配置，不直接复用 Electron 主进程代码。

各端共享的数据契约或纯函数应在需求明确后提取到单独的共享目录，避免提前建立无实际复用价值的抽象。

具体启动方式见仓库根目录 [README](../README.md)。

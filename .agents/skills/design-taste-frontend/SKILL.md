# 行情日报视觉审查

视觉阅读：面向 A 股复盘读者的高密度收盘报告，采用克制、可信、编辑化的金融信息语言。

参数：`DESIGN_VARIANCE=4`、`MOTION_INTENSITY=1`、`VISUAL_DENSITY=8`。

## 审查重点

- 保持 18 日报告的整页容器、三栏首屏、编号区块和红涨绿跌语义。
- 不将报告改造成营销落地页、Bento 卡片墙或玻璃拟态仪表盘。
- 不用紫蓝渐变、装饰光斑、夸张阴影和无意义动效。
- 不用巨大标题挤压首屏数据；温度、主线和三项核心行情应首屏可见。
- 不因字段缺失删除区块；用结构稳定的“待补充”状态保持日期间可比性。
- 控制视觉强调层级，避免每个区块都成为独立浮动卡片。
- 最终对照 `docs/每日A股复盘.jpg` 与 18 日 HTML 检查一致性。

可用性、数据真实性和内容清晰度优先于审美变化。

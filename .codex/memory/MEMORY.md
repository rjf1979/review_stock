# 项目记忆 · 行情日报

主产品为 Electron 桌面版；Web 端是官网、下载入口和运维后台。

## 架构与数据
- 桌面端在 `src/desktop/`，Web 平台在 `src/web/`，未来移动端预留 `src/app/`；桌面端使用 Electron `userData` 下的 `sql.js` SQLite。
- 工作日 `09:30-11:30、13:00-15:00` 自动刷新；闭市展示最后交易数据，手动刷新可重新获取最终行情。
- 交易日 12:00 生成午间快照，16:00 生成收盘复盘；支持托盘、通知、本地归档、单实例锁和失败重试。

## 实时行情与 UI
- 默认无边框最大化并锁定工作区，顶栏只保留最小化和关闭到托盘；实时盘面铺满可用宽度，尽量一屏展示且不使用数据板块滚动。
- 股指期货界面暂时隐藏，后端采集保留；缺失数据不补零、不估算。
- 各类行情分别标记 `realtime` / `last-trade`；全市场有效样本少于 1000 判无效。
- 领涨/领跌改为东方财富概念板块，各 5 条并过滤非题材分类；行业资金流仍保持行业口径。
- 每日复盘采用编辑化报告布局，已取消自选股观察和龙虎榜；对应独立页面保留。

## Windows 安装包
- NSIS 输出 x64/ia32 包；同版本提示无需更新，新版本询问后覆盖，旧版本禁止降级。
- 安装前、卸载前通过 `taskkill /F /T /IM HangqingDesktop.exe` 结束主程序及 Electron 子进程；安装/卸载完成后安装器自动关闭。
- 卸载只删除程序、依赖、快捷方式和卸载登记；保留 AppData 中的数据库、复盘、设置与缓存。
- 双架构安装包已验证；快捷方式显式绑定 `app-icon.ico`，任务栏使用固定 AppUserModelID。

## 当前风险
- 安装包尚未代码签名，Windows 可能提示未知发布者。

# 项目记忆 · 行情日报

## 当前架构
- 主产品为 `src/desktop/` Electron 桌面版；`src/web/` 仅为桌面版官网和下载入口；`src/app/` 为未来移动端占位。
- 设置、自选、快照和复盘保存在 Electron `userData` 下的 SQLite，无需云端账号。
- A 股数据只使用公开接口和确定性计算；缺失值明确标注，不使用 AI 生成复盘结论，不以当前数据冒充历史行情。

## 桌面功能
- 默认明亮皮肤，右上角 Switch 可持久化切换明暗主题；赞助弹窗内置已脱敏的支付宝收款码。
- 实时页按交易时段刷新；闭市后若缓存仍属前一交易日会重新抓取当天收盘数据，自选报价缓存按交易日隔离；盘前、午休和周末复用对应最近交易日数据。
- 自选股上限 100 只，一行 3 图、一屏 6 只；蜡烛日 K 含 MA5/10/20/60 和 VOL，涨红跌绿，并发受控且按视口懒渲染。
- 龙虎榜显示买卖金额、净额和前五席位；机构按公开名称标注，其他资金显示具体营业部；上榜股票可直接加入自选。
- 每日复盘使用确定性模板，成功后完整落地 SQLite；切页优先内存缓存，重启后优先本地快照，收盘任务强制刷新正式版本。
- 设置页展示当前版本和结构化更新日志；版本号与最新日志由 `npm run check` 强制校验。

## 发布状态
- 最新线上版本为 `v0.2.1`（提交 `2cec3ac`），远程 `main`、Release 标签和 README 双架构下载链接均已核验。
- Release 含 x64/ia32 NSIS 安装包和最新图标；卸载保留用户数据库与缓存。
- README 已展示实时行情、自选股、每日复盘、龙虎榜、历史报告 5 个业务页面，不展示设置页。

## 风险与下一步
- 安装包尚未代码签名，Windows 可能提示未知发布者。
- 构建需配置 Electron/npm 镜像；winCodeSign 若受符号链接权限影响，可跳过自动编辑并用缓存 `rcedit` 写入版本和图标。
- 后续版本必须同步 package、lock、NSIS、更新日志、README、x64/ia32 Release 资产和 SHA-256。

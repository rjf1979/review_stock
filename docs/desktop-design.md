## 一、定位与合规框架

### 产品定位
- **一句话**：免费的 A 股行情 + 每日复盘桌面工具。
- **形态**：Windows/Mac 桌面应用（实时行情 + 收盘复盘 + 龙虎榜/板块），配套一个介绍官网。
- **本地优先触达**：桌面版本地主动查看 + 可选系统通知，平台不再依赖邮件订阅。

### 合规定位（券商红线，必须守住）
- 本软件是**行情数据展示与整理工具**，不是投资顾问、不是券商。
- 不荐股、不给买卖建议、不承诺收益、不预测"会涨会跌"。
- 「市场温度」「情绪指标」均为**统计性描述**，不代表未来走势，不构成买卖信号。
- 页面/官网**显眼位置**放免责声明。

## 二、技术架构（已定性）

```
┌──────────────────────────────────────────────────┐
│  Electron 桌面壳（Chromium + Node 运行时）             │
│  ├─ 前端 UI：Vue 3（实时行情/复盘/龙虎榜…）         │
│  └─ 本地 Node 取数服务（运行在用户本地）             │
│      └─ 复用 server/review.js 取数逻辑             │
│          ├─ 腾讯 qt.gtimg.cn（指数/个股/K线/港美股）│
│          ├─ 东财 push2delay/push2ex/datacenter     │
│          └─ 东财快讯 newsapi（今日要闻）           │
└──────────────────────────────────────────────────┘
```

- **Electron**：当前原型直接复用 Node 取数逻辑和 Chromium 页面，先保证多用户安装、数据隔离和功能稳定，再评估安装包体积优化。
- **本地 Node 服务**：在应用内启动取数服务，UI 经 HTTP `localhost` 端口调用；取数失败自动降级备源、可重试。
- **SQLite**：正式版本保存每个操作系统用户的设置、自选股、行情快照和复盘索引，不要求用户安装数据库服务。
- **前端**：Vue 3（与现有平台前端同栈，学习成本低）。

### 关键原则（用户已确认）
- **数据抓取在用户本地机器完成**：桌面版内 Node sidecar 直接连腾讯/东财公开接口取数，**不经过任何服务器中转**。
- **软件方只提供软件、不提供数据源**：数据源是公开免费的，由软件在用户本地抓取并展示；官网/软件明示「数据来自公开来源」。
- **官网 = 现有 dailystock 站点改造**：保持现有视觉风格（theme-base 设计系统），内容改为「介绍桌面软件 + 下载」。站点本身不再承载数据抓取/提供。

### 数据源调研结论（定稿）

> 2026-08 调研。原则：**核心行情腾讯、深度数据东财、要闻东财快讯**；全部公开免费接口、桌面本地直连，不经任何服务器中转。

| 数据 | 首选源 | 备胎 / 说明 |
| --- | --- | --- |
| 指数 / 个股 / 港美股实时 | 腾讯 `qt.gtimg.cn`（不封 IP、免鉴权、一次多标的；GBK 编码需转码） | 东财 `push2delay`（指数兜底） |
| 股指期货最新价 / 成交量 / 持仓量 / 昨结算 | 东方财富公开期货接口 `futsseapi` | 约 15 分钟延时；不能作为盘中实时行情授权替代 |
| 股指期货多单 / 空单 / 多空差 | 东方财富 `RPT_FUTU_DAILYPOSITION` 公开会员结算数据 | 上一交易日结算口径；多空差按真实多单减空单，不估算 |
| 全市场宽度 / 两市成交额 | 东财 `push2delay` `clist/get` 分页（100 条/页，样本校验后计算） | 采集期间使用 SQLite 最近快照 |
| 盘口异动 | 东财 `push2ex/getAllStockChanges`（大笔买入/卖出、急速拉升、猛烈打压、封板/打开涨跌停） | 5 秒本地缓存，跟随实时行情刷新；按面板尺寸轮换展示股票名称、代码、异动情况、时间和指标；闭市后直接使用最后交易快照；无数据时显示空状态 |
| 涨停池 / 连板梯队 | 东财 `push2ex` `getTopicZTPool` | 沪深交易所官方 |
| 跌停池 / 炸板池 | 东财 `push2ex` `getTopicDTPool` / `getTopicZBPool` | 全市场快照复算 |
| 龙虎榜 | 东财 `datacenter-web` `RPT_DAILYBILLBOARD_DETAILSNEW` | 沪深交易所官方 |
| 板块涨跌 / 主力资金流 | 东财 `push2delay` `clist/get`（`f3` 涨跌幅、`f62` 主力净流入） | 新浪（资金流） |
| 历史 K 线（技术指标） | 腾讯 `web.ifzq.gtimg.cn` `fqkline` | Baostock 补数 |
| 今日要闻 | 东财快讯 `newsapi`（免鉴权；JSONP 需去 `var` 前缀） | 财联社 v1（需 sign 签名） |
| 港美股 | 腾讯（`hkHSI`/`hkHSTECH`/`usIXIC`/`usINX`/`usDJI`） | 雅虎 |

**东财风控铁律（2025 起加强）**：所有东财请求尽量限流 ≥1s 间隔 + 备胎降级；`push2` 主域被反爬 → 统一走 `push2delay` 镜像；单项失败逐项降级，不中断整份报告。

**已落地（`review-core.js`）**：腾讯指数/个股/港美股、东财全市场宽度分页、涨停/跌停/炸板池、盘口异动、龙虎榜、板块强弱+资金流、东财快讯要闻、技术面温度（K 线算 MACD/KDJ/RSI）、自选股默认 8 只大票（`WATCHLIST`）。全市场分页在后台串行采集，桌面接口先返回最近快照或“采集中”状态，不阻塞首屏。

### 3.2 视图明细

| 视图 | 内容 | 数据/交互 |
| --- | --- | --- |
| **实时行情** | 指数条（自动刷新 3s）+ 股指期货行情与会员多空结算 + 全市场宽度（红盘率/上涨/下跌/平盘/涨跌比/涨停/跌停/炸板/成交额）+ 涨幅/跌幅/成交额榜 + 领涨/领跌概念 + 行业主力资金 + 盘口异动（八类实时事件） | 腾讯 + 东财；期指行情约 15 分钟延时，多空为上一交易日结算；全市场分页后台采集并缓存，盘口异动按 5 秒缓存跟随实时行情刷新 |
| **自选股** | 自选增删（本地存储）+ 实时报价 + 分时/日 K 线图 | 腾讯 K 线 |
| **大盘概况** | 7 指数详情表（收盘/涨跌/成交额/PE）+ 行业板块涨幅 Top + 两市成交额 | 东财 |
| **每日复盘** | 午间快照与收盘复盘：编辑化报告布局，包含市场温度/情绪指标/市场宽度/指数/板块资金流/连板/海外/要闻/明日观察，不含自选股观察和龙虎榜 | 交易日 12:00、16:00 生成，Markdown 渲染 |
| **龙虎榜** | 上榜个股 / 涨跌幅 / 净买入 / 上榜原因 表格 | 东财 datacenter |
| **历史报告** | 历史复盘日期列表 → 查看历史报告 | 本地或平台 |
| **设置** | 数据源切换、刷新频率、主题（亮/暗）、通知开关、关于/免责声明 | — |

### 3.3 关键交互
- **托盘常驻**：最小化到系统托盘，交易日 12:00 和 16:00 各自动生成一次复盘，并可发送**系统通知**（可关）。
- **红涨绿跌**：A 股惯例。
- **温度仪表盘**：当日市场温度 0-100 环形/进度展示 + 量价/技术分解。

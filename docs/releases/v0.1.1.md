# 行情日报 Desktop v0.1.1

首个通过 GitHub Releases 分发的 Windows 桌面版本。

## 主要功能

- 实时行情工作台：指数、全市场宽度、涨跌停/炸板、概念强弱、行业资金、榜单与盘口异动。
- 闭市后保留并展示最近一次有效交易数据。
- 自选股、K 线、龙虎榜和历史复盘独立视图。
- 工作日 12:00 生成午间快照，16:00 生成收盘复盘。
- SQLite 本地保存设置、自选股、行情快照和复盘记录。
- 默认适配屏幕工作区，支持最小化、关闭到托盘和系统通知。
- 新增统一的主程序、任务栏、托盘、快捷方式、安装器和卸载器图标。

## 安装与升级

- `x64` 适用于绝大多数 64 位 Windows 10/11 电脑。
- `ia32` 仅用于 32 位 Windows。
- 新版本安装包会询问是否覆盖升级。
- 相同版本不会重复安装，旧版本安装包不能降级覆盖。
- 卸载会删除程序和快捷方式，但保留本地数据库、复盘、设置与缓存。

## 注意事项

- 安装包尚未进行代码签名，Windows 可能显示“未知发布者”。

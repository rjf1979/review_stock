# 行情日报 Desktop v0.2.2

本版本加入桌面端在线升级能力。由于 `v0.2.1` 尚未包含更新器，用户需要手工安装本版本一次；从 `v0.2.2` 开始，后续版本可在应用内完成升级。

## 新增功能

- 应用启动 15 秒后自动检查更新，此后每 6 小时定时检查。
- 设置页支持手动检查、失败重试、下载进度与立即升级。
- 按当前 Windows 架构自动选择 x64 或 ia32 升级包。
- 下载完成后同时校验文件大小和 SHA-256，不一致时拒绝安装并清理临时文件。
- 升级沿用现有 NSIS 覆盖安装逻辑，保留 SQLite、自选股、设置、行情快照和历史复盘。

## 验证

- 更新器版本比较、架构选择、HTTPS 限制、流式下载和哈希失败清理测试通过。
- 桌面端语法、更新日志与 x64 打包内容检查通过。
- 官网更新清单 GET/HEAD、缓存策略与路径保护检查通过。

## 注意事项

- 安装包尚未进行 Windows 代码签名，首次安装仍可能显示“未知发布者”。
- 在线升级包只接受 HTTPS 地址，并以官网清单中的 SHA-256 校验完整性。
- 本软件仅用于行情展示和整理，不构成任何投资建议。

# 行情日报 Desktop v0.2.1

本版本修复收盘后首次启动与自选股行情的跨日缓存问题。

## 修复内容

- 工作日闭市后首次打开软件时，如果本地快照仍属于前一交易日，自动重新获取当天收盘行情。
- 自选股报价缓存按交易日期隔离，避免后台进程跨日后继续展示昨日数据。
- 保留盘前读取上一交易日、午休读取当日盘中数据、周末读取周五数据的既有行为。

- 日期边界自动化测试通过。
- 桌面端语法、更新日志和构建检查通过。
- Windows x64 与 ia32 安装包构建及校验通过。
